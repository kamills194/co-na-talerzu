## Komendy użyte do analizy

Archiwum rozpakowano do nowego, pustego katalogu /tmp/site-v7 poza repo. Skrypty
analityczne zapisano w osobnym katalogu /tmp/cnt011-tools i uruchamiano stamtąd,
przekazując ścieżki jako argumenty (python3 -I). Niczego z archiwum nie uruchamiano.

- sha256sum, unzip -l, unzip -z, unzip -Z1 (kontrola ścieżek), unzip -q -d /tmp/site-v7
- find -type l (brak dowiązań symbolicznych)
- cat / head / cut / sed na plikach tekstowych archiwum i apps/web/src
- grep: klucze localStorage, wywołania fetch, adresy URL, env.*, wzorce sekretów
  i nazwy plików wrażliwych, wzmianki o alergenach, tekst kierowany do AI
- python3 -I analyze.py — statyczne parsowanie dist/data.js, sourced-recipes.js,
  catalog.js (regex + json), zliczenia pól, jednostek, kategorii, porównanie nazw z MVP
- python3 -I meals.py — rozkład sześciu kategorii według src/meal-types.js
- python3 -I list90.py — lista ID i polskich tytułów 90 odnośników
- git log, git status, git add (dwa pliki), git commit

Skrypty pomocnicze nie są częścią repo.
