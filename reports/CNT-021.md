# CNT-021 — przegląd kodu apps/web po przejęciu prac

Data: 2026-11-16. Gałąź: cnt-021-przeglad-kodu. SHA kodu: 82a47eca986b8647270ff73a316ca25f368b6a1c.
Baza: main aff161bd50e63136e1ccae9c47bc4eefbd925ba8.

## Cel

Przejrzeć działający kod PWA i poprawić znalezione błędy bez zmiany stacku,
klucza localStorage (co-na-talerz:v1) i identyfikatorów aplikacji.

## Wynik

| Obszar | Problem | Poprawka |
| --- | --- | --- |
| sw.js / build.mjs | Pamięć podręczna cache-first miała stałą nazwę (v4); bez ręcznej zmiany zainstalowani użytkownicy nie dostaliby nowych przepisów ani poprawek | Build wpisuje do dist/sw.js nazwę z hasha treści plików powłoki |
| sw.js | Otwarcie aplikacji offline z parametrami w adresie kończyło się błędem przeglądarki | Nawigacja offline wraca do zapisanego index.html |
| offers-bot / offer-parser | robots.txt: druga linia User-agent w tej samej grupie wyłączała reguły dla `*` (bot mógł czytać zabronione ścieżki); wzorce z `$` były traktowane dosłownie | Funkcja robotsDisallows z obsługą grup i kotwicy `$`, z testem |
| storage.js | Kopia z własnym wpisem o ID równym ID produktu (np. milk) przechodziła walidację; po dodaniu składników zapis trwale się nie udawał | Walidacja odrzuca taki wpis |
| domain.js | Nowa pozycja listy nie była zaokrąglana tak jak sumowana (np. 33,333333…) | Wspólne zaokrąglenie do 0,001 |
| app.js | Po kliknięciu serca, kategorii lub pola zakupów fokus klawiatury znikał; wybór kategorii zamykał panel wykluczeń; licznik ofert bota mógł różnić się od listy; brak zabezpieczenia przy nieistniejącej pozycji | Przywracanie fokusu, zachowanie stanu panelu, wspólna funkcja currentAuto, zabezpieczenia |

## Komendy
